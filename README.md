# 玉兔纯净基础分支与独立救援预览

此分支是模型提供解耦、独立救援宿主的首批源码预览，不是完整玉兔应用的可安装发行版，不含旧仓库历史、个人模型配置、凭据、聊天、记忆、素材、模型权重或运行产物。

## 已能验证的行为

- Provider配置可选择OpenAI兼容的HTTPS服务或受控回环接口；模型/能力/连接参数分开，密钥只在执行宿主的环境变量中读取，不进前端目录。
- 救援服务单独启动，不导入或调用玉兔工作台；可登录、发送补充、看持久进展，API维修模型可以直接回复/调维修工具。
- 宿主按独立维修身份授权，默认生产激活关闭；只允许明确清单中的程序文件，拒绝数据/凭据/救援路径、越界、符号链接与陈旧修改。
- 候选暂存与运行程序分开，固定命令核验后才可激活；重启失败回滚受管程序，不替换聊天/记忆。中断或进程状态不确定时暂停，不盲目重复操作。
- API维修有独立请求/输出上限。上限不是账单金额；目前记录调用次数，不能宣称精确token计费。每次最多4轮，进程重启不重置已用请求数。
- Windows独立WinForms/WebView2窗口源码单独构建，不复用主工作台EXE；闭窗不终止独立服务。源码不携带Node、WebView2或.NET二进制。

## 运行（源码验证）

需要Node.js 22或更高版本（支持AbortSignal.any）；本轮在Node26验证。没有第三方npm运行依赖。Windows窗口需.NET 8 Windows和WebView2；发布时应独立self-contained打包并保留第三方许可。

1. 把 `examples/providers.example.json` 和 `rescue.example.json` 放到源码/可修改目录之外，替换路径、真实模型名与HTTPS接口。
2. 仅在独立宿主环境配置 `YUTU_RESCUE_OWNER_TOKEN`（高熵随机值）、`YUTU_MODEL_API_KEY`，远端维修需另一个最小授权令牌。不要把这些值写入Git、终端历史或模型消息。
3. 配置 `appRoot`、独立 `rescueHome`、`editableFiles`。默认 `activationEnabled=false`，不要为试用改为true。
4. 源码目录运行 `node apps/rescue/rescue-service.mjs --config /absolute/path/to/private/rescue.json`，访问回环 `http://127.0.0.1:48950`。项目源仓库中的对应路径是 `tools/rescue/rescue-service.mjs`。
5. 远端设备通过已登记SSH目标建立本地48950→传奇回环48950的专用隧道。`rescue-client.mjs --connection <独立连接JSON>` 从stdin接收JSON维修操作；不收任意SSH命令或目标参数，不关闭主机指纹验证。
6. `npm test` 验证Provider与救援核心。所有测试创建独立临时程序和合成输入，不读取真实聊天。

## 安全与尚未交付的生产部分

**这是可信维修代码能力，不是针对同账户恶意代码的安全沙箱。** 路径白名单只能约束这套接口；已有全面文件/终端权限的模型若与救援同OS账户，仍可能绕过它。生产必须用独立Windows服务身份/ACL、隔离凭据、独立运行时/版本目录和受控升级权限，并同时检查主工具链的权限，验收后才授予少数维修身份激活权。不能只把一个开关改true就宣传“部分模型已严格隔离”。

生产重启命令必须由主人/安装器配置为固定、已审查的程序与argv，不能来自模型自然语言；健康检查需包含明确服务/版本身份，不只看HTTP200。Windows命令超时可能留下子进程，当前会暂停呈报，不保证自动清掉整棵进程树。首次生产安装还需补经过验证的固定服务控制适配器、失败时自动打开备用窗口的监测入口、真实主程序崩溃恢复验收。这些未完成，当前未接入玉兔的自动维修权限，也没有安装或OTA。

远端SSH要求设备有网络、SSH服务和已授权密钥；本机API需要独立凭据与网络，不能修复硬盘/系统故障。备用路线不自动借用主程序key，不擅自切换付费模型。

## Git与发布边界

纯净导出使用固定文件清单；不从整个工作区递归打包，不从Git旧历史提取内容。新根提交推到旧仓库的独立 `share/clean` 分支，不删除/改写旧分支，不改变仓库公开性。分支没有旧parent，不代表旧仓库其他分支可以公开；真正对外发布应使用审核后的独立仓库或仅导出该分支。

首批只导出本文所列新基础模块及其合成测试/示例。现有完整玉兔前端、Mac部门系统、个人素材和设备运维代码尚未整体脱敏并迁入，不能把此分支宣传为完整产品。保留源码权利；未确定整体开源许可证前不默认授予第三方重新分发全部玉兔代码/素材的许可。
